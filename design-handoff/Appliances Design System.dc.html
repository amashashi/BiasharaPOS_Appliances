07

Ufikivu & lugha

Accessibility & localization
  • All text ≥ 4.5:1 contrast; body on green uses white.
  • Swahili is first-class — labels sized for Swahili length first.
  • Date format dd/MM/yyyy; templates authored in both languages.
  • Full keyboard in back office; touch + barcode scanner at POS.
  • Color is never the only signal — badges pair tint + icon + label.
08

Utawala

Governance
  • Tokens live in packages/ui/tokens.ts — no hex literals in feature code.
  • Inherited core palette changes need core brand-owner sign-off.
  • Sub-brand tokens (accent, domain statuses) owned by this product.
  • New components ship with both locales and both surfaces considered.
